# エディター切替

テキストエディターを表示したとき、選択済みの文書 URI に対応する形式で項目を表示して検証する。
形式を選んだことがない文書には装飾と診断を加えない。表示から外れたエディターの装飾を破棄し、
最後の表示が隠れた文書の診断も消す。同じ URI の文書を再度表示すると、選んである形式から
最新の内容を解析して装飾と診断を更新する。

形式を選び始めた文書の URI を保持し、Quick Pick を閉じたときに別の editor が active でも
選択先を付け替えない。形式が指定する文字コードと文書の文字コードが異なる場合、
未保存の編集がなければ標準 API で同じ URI を再読込する。dirty、untitled、close、
再読込失敗、適用後の文字コード不一致は安全に停止し、選択・装飾・診断を解除して通知する。
拡張機能は保存、書換、文字コードの自動復元を行わない。

各文書は独立して解析を始める。同じ形式を使う別文書のヘッダーやレコード種別は、
その文書の項目表示に影響しない。同じ文書を複数のエディターに表示した場合は、1回の解析結果を
各表示に適用する。項目境界とカーソル位置の項目を表示し、エディターごとに独立した装飾を持つ。
検証結果は文書 URI ごとに一度だけ保持し、分割エディターで重複しない。

編集、保存、設定や文字コードの変更、非表示、close、拡張機能の破棄で古い処理を失効させる。
完了した解析は URI、文書版、文字コード、形式、世代が現在の状態と一致するときだけ適用し、
遅れて届いた古い結果で最新の表示や診断を上書きしない。

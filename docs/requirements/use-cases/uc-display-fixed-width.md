# 固定長の項目表示

コマンドパレットで `JFixedViewer: 固定長のファイル形式を選択` を実行し、
組み込み形式を選ぶ。項目には既定で境界線が表示される。設定で境界線、交互の背景色、
区切り記号を切り替え、色や境界線の太さを調整できる。表示設定は文書の URI に応じて適用される。
装飾は表示だけで、文書の内容や保存結果を変更しない。

## 表示ルール

- 選択した形式の行定義を順に照合する。行の条件と現在のモードが最初に一致した定義の項目幅を使う。
- 一致した行は、設定したキャプチャに従ってモードを設定または解除できる。
  同じ形式の後続行には、そのモードを使う。
- 空行、空白文字だけの行、どの行定義にも一致しない行には、項目を表示しない。
- 項目の境界は、幅を順に足して VS Code の UTF-16 座標で表す。
  一致した行が短くても、設定された項目の幅は切り詰めない。
- ホバーには行名、1から数えた開始位置と終了位置、桁数を日本語で表示する。
- `line` は項目終端に縦線、`alternating` は偶数項目の文字がある範囲に背景色、`marker` は `│` を表示する。
  色を指定しない場合はテーマに合わせる。交互色には半透明度を使う。
- 行より後ろにある定義上の終端は描画しない。行末に一致する終端は描画する。
  短い行でも、表示されるホバーの開始位置、終了位置、幅は定義に基づく。

形式を適用した文書を編集、追加、削除すると、変更が止まってから自動で装飾とホバーを更新する。
ヘッダーやモードを決める行の変更も後続行に反映する。形式を選んでいない文書と、装飾を解除した文書には
編集後も装飾を付けない。分割して表示した同じ文書には、同じ解析結果を反映する。

選んだ形式は拡張機能が有効な間、文書 URI ごとに保持する。形式を選び直さなくても、同じ URI を
閉じてから開くと、現在の文書の内容を再解析して表示する。

境界表示は `jfixedviewer.boundaryStyle`（`line`、`alternating`、`marker`）、
`jfixedviewer.boundaryColor`（空または `#RRGGBB`）、
`jfixedviewer.boundaryWidth`（`1`〜`4`）で設定できる。既定値は `line`、空、`1`。

アクティブなテキストエディターがないときに形式を選んでも、装飾は適用されない。

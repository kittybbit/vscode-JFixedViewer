# 固定長の項目表示

コマンドパレットで `JFixedViewer: 固定長のファイル形式を選択` を実行し、
組み込み形式を選ぶ。アクティブなテキストエディターに、該当する行の項目の区切りが表示される。
文書の内容は変わらない。

## 表示ルール

- 選択した形式の行定義を順に照合する。行の条件と現在のモードが最初に一致した定義の項目幅を使う。
- 一致した行は、設定したキャプチャに従ってモードを設定または解除できる。
  同じ形式の後続行には、そのモードを使う。
- 空行、空白文字だけの行、どの行定義にも一致しない行には、項目を表示しない。
- 項目の境界は、幅を順に足して VS Code の UTF-16 座標で表す。
  一致した行が短くても、設定された項目の幅は切り詰めない。
- ホバーには行名、1から数えた開始位置と終了位置、桁数を日本語で表示する。

文書を編集した後に装飾を更新するには、コマンドで形式を選び直す。
アクティブなテキストエディターがないときに形式を選んでも、装飾は適用されない。

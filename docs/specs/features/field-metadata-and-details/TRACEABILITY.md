# フィールドメタデータと詳細表示の要件と検証

[仕様](SPECS.md)の受け入れ条件と、[計画](TASKS.md)の検証を対応付ける。
実施した検証の入力と結果は各スライスの証跡に記録する。

<!-- markdownlint-disable MD013 -->

| 要件またはユースケース                                                                                                                            | スライス | 検証                                                                                                                                                                    |
| ------------------------------------------------------------------------------------------------------------------------------------------------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 項目名、幅、型、番号、位置と旧 `columns` 互換                                                                                                     | 1        | JPX のメタデータとローダー注入した旧 `columns` フィクスチャの境界・位置・ホバーを共通回帰テストで確認する。                                                             |
| [固定長の項目表示](../../../requirements/use-cases/uc-display-fixed-width.md)                                                                     | 1、2     | 短い行、UTF-16、境界、各表示方式、編集後の更新を共通テストで確認する。両ホストで項目名、位置、強調を確認する。                                                          |
| [エディター切替](../../../requirements/use-cases/uc-switch-editors.md)と[項目の装飾解除](../../../requirements/use-cases/uc-clear-decorations.md) | 1        | 分割ごとのカーソル、表示の切替、非表示化、解除、再表示、拡張の破棄を共通テストで確認する。                                                                              |
| JPX の仕様照合とサンプル                                                                                                                          | 1        | JPX v4.0 の全83項目、657バイト、レコード区分、ファイル識別と配信名を照合し、サンプルと表示を確認する。                                                                  |
| 全銀の仕様照合とサンプル                                                                                                                          | 2        | 全銀協 AP-I-13 と178行・2,699項目を照合し、公式ページ・表・行との対応を記録する。33サンプルの構造、列挙値、複合項目、条件付き値と分岐を共通テストと独立監査で確認する。 |
| 互換性とプライバシー                                                                                                                              | 1、2     | 両ホストのビルドと安定版・最小版のスモーク、アーキテクチャテストと、内容とテレメトリの回帰を確認する。                                                                  |

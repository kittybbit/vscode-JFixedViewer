# Dependabot 警告の解消要件

## 目的

JFixedViewer の npm 依存関係を更新し、Dependabot が報告した脆弱なバージョンを依存ツリーから除く。
利用者は更新後もデスクトップ版と Web 版で固定長ファイルを同じ手順で確認できる。

## 根拠

- 受付時点の [Dependabot 警告](https://github.com/kittybbit/vscode-JFixedViewer/security/dependabot)は
  76 件。対象は `package-lock.json` に含まれる 25 パッケージ。
- 維持する利用者向けの挙動は[固定長表示のユースケース](../../../requirements/use-cases/README.md)に従う。

## 要件と受け入れ条件

- 受付時点の全警告について、修正後の `package-lock.json` に該当するパッケージと脆弱範囲の組み合わせが
  ないことを確認する。既定ブランチへの反映後、Dependabot の再評価結果を確認する。
- `npm audit` で追加の指摘も確認し、脆弱性 0 件を合格条件とする。
- `npm ci` で依存関係を再現できる。型チェック、両ホスト向けの本番ビルド、アーキテクチャ検査、
  デスクトップ安定版と最小対応版、Web 安定版で既存のテストを通す。
- 更新した配布ツールで VSIX を生成できる。生成物にデスクトップ版と Web 版のバンドルを含める。
- 組み込みの全銀形式と JPX 形式、装飾とホバー、エディター切替の挙動を保つ。文書の内容を変更しない。
  テレメトリのイベント一覧、利用者のオプトアウト、イベントデータの制約も保つ。

## 決定事項と影響

- 依存パッケージのバージョン更新を認める。実行時依存は両ホストで動作することを確認し、
  テレメトリ SDK は引き続きインフラストラクチャ層で扱う。
- 開発・検証用依存の更新も、テストの実行条件や生成される拡張に影響する場合がある。
  [検証方針](../../validation.md)に従い、更新前後で影響を受けるチェックを比較する。

## 互換性

今回の計画では VS Code の最低対応版 1.75.0 を維持する。開発・検証用の依存関係は CI と同じ
Node.js 24 で検証する。最小対応版の引き上げが必要と判明した場合は、理由と必要な最小バージョンを
示して再計画し、対応バージョンの宣言、検証、変更履歴をそろえる。

## 対象外

- 固定長表示の機能追加や、依存更新と関係しないリファクタリング。
- Dependabot 警告の手動却下や、監査・回帰テストの検査範囲の縮小。

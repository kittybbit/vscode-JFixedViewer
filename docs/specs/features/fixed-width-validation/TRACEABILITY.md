# 固定長レコード検証の要件と検証

<!-- markdownlint-disable MD013 MD060 -->

| 要件またはユースケース | スライス | 検証                                                                            |
| ---------------------- | -------- | ------------------------------------------------------------------------------- |
| R1: UTF-16 の長さ      | 1        | Pass: 短い AB は [1,2)、空入力 [0,0)、超過・サロゲート・旧 columns              |
| R2: N 型の文字種       | 1        | Pass: 数字・全 SP・混在・英字・全角数字・短い項目、C 等の対象外                 |
| R3: 未知レコード       | 1        | Pass: XYZ の全体範囲 [0,3)、モード・空白行・別文書の初期化                      |
| R4: 更新と分割表示     | 1        | Pass: 形式選択・編集・キャンセル・分割 URI・待機更新                            |
| R5: 無効化と解除       | 1        | Pass: resource scope・無効/再有効・不正型の既定 true・解除                      |
| R6: 寿命               | 1        | Pass: 非表示・閉じる/再表示・破棄・古い待機処理                                 |
| R7: 正常なサンプル     | 1        | Pass: 全銀33形式215レコードと JPX サンプルの診断0件                             |
| R8: 既存契約           | 1        | Pass: 既存回帰・architecture・desktop 1.145.2/1.75.0・Web smoke                 |
| 上限と性能             | 1        | Pass: 0/1000件は通知なし、1001件は `VALIDATION_LIMIT` を先頭 [0,0)、Information |
| プライバシー           | 1        | Pass: 内容を含めない診断文、診断専用テレメトリなし、既存オプトアウト維持        |
| 既存の表示・解除・切替 | 1        | Pass: `decorate()` 互換、装飾・ホバー・強調・切替の回帰                         |

<!-- markdownlint-enable MD013 MD060 -->

全項目は pass。上限後も装飾・モード遷移は継続する。10,000行比較、実装ベース、入力 hash、
コマンド、生出力と終了コードは [計画と実装記録](TASKS.md)および証跡フォルダーを参照する。

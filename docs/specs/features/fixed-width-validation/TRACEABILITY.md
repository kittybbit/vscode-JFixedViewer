# 固定長レコード検証の要件と検証

| 要件またはユースケース | スライス | 検証 |
| --- | --- | --- |
| R1: UTF-16 の長さ | 1 | 正常・不足・超過・サロゲート・旧 columns、全銀33形式と JPX |
| R2: N 型の文字種 | 1 | 数字・全 SP・混在・英字・全角数字・タブ、短い項目の抑制、C 等の対象外 |
| R3: 未知レコード | 1 | 不一致行、モード依存、空白行、別文書のモード初期化 |
| R4: 更新と分割表示 | 1 | 形式選択・変更・キャンセル・100ms待機・編集の集約、URI 単位の重複排除 |
| R5: 無効化と解除 | 1 | resource scope、無効・再有効化、不正な設定型、形式解除と古い更新の取消 |
| R6: 寿命 | 1 | 最後の表示を隠す、分割表示が残る、閉じる・再表示、破棄・起動失敗 |
| R7: 正常なサンプル | 1 | 全銀33形式215レコードと JPX の既存サンプルに診断なし |
| R8: 既存契約 | 1 | 既存回帰、両バンドル、architecture、desktop 安定版・1.75.0・Web smoke |
| 上限と性能 | 1 | 0/1000/1001件、打切り情報、上限後の装飾・モード、1万行の有効/無効比較 |
| プライバシー | 1 | 値を含めない診断、診断による追加テレメトリなし、既存オプトアウト |
| 既存の表示・解除・切替 | 1 | 新規検証ユースケースと既存ユースケースの整合、装飾・ホバー・強調の全回帰 |

計画時点では全製品チェックが未実施。正確な結果と入力識別情報は
[計画](TASKS.md)および実装担当が作成する参照可能な証跡に記録する。

# SDD 導入の要件と検証

| 要件  | スライス  | 検証                                         |
| ----- | --------- | -------------------------------------------- |
| SDD-1 | 1         | 手順のシナリオ、文書検証、最新ヘッドの CI    |
| SDD-2 | 2、3      | 移行前後の回帰テスト、3つの実ホスト          |
| SDD-3 | 3         | 依存ルールの許可例・禁止例、両バンドル       |
| SDD-4 | 再計画、1 | 日本語の文書・ロール設定の確認、独立レビュー |

- SDD-1 は担当の振り分け、状態遷移、証跡、承認、スタックでの作業順を検証する。
  先行ブランチを対象にする後続 PR でも CodeQL と Verify が動くことを確認する。
- SDD-2 は行判定、モードと同じ形式での状態共有、固定長の装飾とホバー、形式の選択と
  キャンセル、エディター切替、破棄、テレメトリ、ホストでの起動を検証する。
- SDD-3 は層をまたぐ import と依存の組み立て、ホストと SDK の境界、静的リソース、
  ブラウザーでの動作を検証する。マニフェストと定義が維持されていることを確認する。
- SDD-4 は再計画の3文書と、スライス1で日本語化する文書・設定内の文章を確認する。
  承認条件、識別子、コマンド、検証条件、各スライスの対象パスを維持する。

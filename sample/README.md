# 固定長形式サンプル

サンプルは JFixedViewer の表示確認用に作成した架空データです。金融機関、取引所、
銘柄や取引の実データではありません。

- [jpx/SH_DER.csv](jpx/SH_DER.csv)
  - 形式: JPX / 四本値（デリバティブ）
  - 仕様: JPX 総研のデータフィードサービス仕様書 v4.0

ファイルを VS Code で開き、コマンド JFixedViewer: 固定長のファイル形式を選択 から
JPX/四本値(デリバティブ) を選びます。ファイル名の .csv は JPX 総研の配信名です。
この形式は CSV ではなく、657文字の固定長データです。

データには日経225先物のコード値を使っています。基準値段は正の架空値、予備項目は
JPX の仕様で指定された空白またはゼロで埋めています。

サンプルのデータ行は仕様にある1バイト文字で構成し、1行のデータ部分を657文字にしています。
行末の LF はレコード区切りとして追加しており、データ部分の幅には含めません。
